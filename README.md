# ONSIGHT 執筆ライブラリ — 作例「Runwayの使い方」の公開版

合同会社ONSIGHT は、記事制作の納品物として、媒体ごとに「執筆ライブラリ」を育てています。記事を 1 本納めるごとに、文体・表記・構成・確認のルールと修正の理由を更新し、お客様だけが開ける限定 URL(非公開リポジトリ)に置く仕組みです。

このリポジトリは、自社記事の作例「Runwayの使い方」(https://onsight-jp.com/ja/writing/runway)で記録したライブラリの公開版で、公開しているのはフォルダの構成・更新履歴・基準書の抜粋 1 章だけです。基準書の全文、チャット型 AI 用の指示文、Claude Code・Codex 用の工程は、有償の範囲に入ります。

## フォルダの構成

| フォルダ | お客様の媒体での中身 | この公開版 |
|---|---|---|
| `rules/` | 基準書 6 章(読者と目的・文体と表記・構成の型・確認の手順・修正の理由の一覧・公開前の点検表) | `04_確認の手順.md` の抜粋だけ |
| `prompts/` | ChatGPT・Claude・Gemini に貼る指示文(下書き用・点検用)と、プロジェクトへの入れ方 | 非公開 |
| `skills/` | Claude Code・Codex 用の工程(構成→下書き→点検→公開後の学習)と、語尾・文のつながり・接続語の係り先を機械で確かめる道具 | 非公開 |
| `log/` | 記事ごとの更新履歴(何を直し、なぜルールに残したか) | 2026-10-16 の 1 本分 |

## お客様の媒体での使い方(3 通り)

| 環境 | 入れ方 | 動くもの |
|---|---|---|
| Claude Code・Codex | 限定 URL からフォルダごと取り込む | 工程と機械チェックまで、当社と同じ流れ |
| ChatGPT・Claude・Gemini | `prompts/` の指示文と `rules/` を、プロジェクト(カスタム指示)に貼る | 下書きと点検の指示文 |
| 人が書く(社内・外注ライター) | `rules/` を読む・配る | 基準書と点検表 |

当社の制作の流れをそのまま移せるのは 1 つ目だけで、下の 2 つには機械チェックと工程の自動実行は移りません。どの形でも、ルール・点検表・修正理由の記録は同じ中身です。
